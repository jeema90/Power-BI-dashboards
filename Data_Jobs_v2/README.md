## Overview

The **Data Jobs Dashboard 2.0** is an interactive Power BI report built to help aspiring data professionals, career switchers, and job seekers explore the data job market through a single-page analytical experience.

Using real-world 2024 data job posting data, this dashboard provides insights into salary trends, skill demand, and job availability, enabling users to make informed career decisions based on current market conditions.

---

## 🎯 Project Objectives

This dashboard was designed to answer key questions such as:

- Which data jobs are currently in highest demand?
- What are the typical salary ranges across different roles?
- Which skills appear most frequently in job postings?
- How do salaries vary between job titles?
- What trends can job seekers use to guide their career path?

## 📈 Dashboard Features

### Key Performance Indicators (KPIs)

The dashboard highlights important metrics including:

- Total Job Count
- Skills Per Job
- Median Annual Salary
- Median Hourly Salary

### Skill Analysis

Users can explore:

- Most requested technical skills
- Skill popularity by percentage
- Skill popularity by total count

### Salary Analysis

Compare compensation across multiple job titles and identify higher-paying career paths within the data industry.
